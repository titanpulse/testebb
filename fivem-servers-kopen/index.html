Veelgestelde vragen

Wat krijg ik als ik een FiveM server koop?

Je krijgt de complete server met de bijbehorende scripts en bestanden. Per product staat op de pagina precies wat erbij zit, inclusief previews van de onderdelen.

Hoe snel ontvang ik mijn FiveM server?

Direct na je betaling. Je bestelling met download en bestelnummer staat meteen in je mailbox. Producten die handmatig worden opgeleverd, regelen we via een ticket in onze Discord.

Kan ik de server eerst bekijken?

Ja. Op de productpagina van elke server vind je previews met foto's en uitleg per onderdeel, zoals politie, garages en jobs.

Welke betaalmethodes kan ik gebruiken?

Je betaalt veilig via Stripe, bijvoorbeeld met iDEAL of creditcard. We zien je betaalgegevens nooit.

Krijg ik hulp bij het installeren?

Ja. Na je aankoop krijg je support in onze Discord server. Heb je meer hulp nodig bij de setup, dan kunnen we die ook voor je verzorgen als dienst.

Klaar om te bestellen?

Kies je product, betaal veilig online en ontvang je bestelling direct per mail.
